# Графический редактор примитивов (Qt + SQLite)

Десктопное приложение на C++ с использованием фреймворка **Qt 5** и базы данных **SQLite**, реализующее графическую сцену для создания геометрических примитивов, динамических связей между ними и отображения состояния в табличной модели.

## Основные возможности

- **Добавление примитивов на сцену:** поддержка эллипсов, прямоугольников и многоугольников с настраиваемыми размерами (ширина, высота и количество вершин для многоугольника).
- **Динамические связи:** соединение любых двух фигур линиями при помощи мыши; при перетаскивании фигур линии автоматически перестраиваются.
- **Хранение в базе данных (SQLite):** каждый объект получает уникальный идентификатор `id` и сохраняется в таблицу `primitives` (ID, тип фигуры, ID связанных фигур, количество фигур данного типа).
- **Отображение и фильтрация (`QSqlTableModel` + `QTableView`):**
  - фильтрация по номеру фигуры (`ID`), типу фигуры и количеству фигур данного типа;
  - фильтрация изменяет только отображение в модели без удаления записей из БД.
- **Каскадное удаление:** при удалении фигуры она удаляется с графической сцены, из модели и базы данных, а все связанные с ней линии и упоминания в связях других фигур очищаются автоматически.
- **Кастомный делегат (`QStyledItemDelegate`):** столбец количества фигур отображается в виде иконок соответствующей формы:
  - `1–3` элемента — 1 фигурка;
  - `4–10` элементов — 2 фигурки;
  - более `10` элементов — 3 фигурки.

## Архитектура проекта

src/
├── main.cpp                    # Точка входа, запуск QApplication и MainWindow
├── db/
│   ├── DatabaseManager.h/.cpp  # Инициализация SQLite, CRUD-операции, пересчёт связей и количества
├── scene/
│   ├── PrimitiveItem.h/.cpp    # ООП-иерархия фигур (Base, Ellipse, Rectangle, Polygon)
│   ├── ConnectionLine.h/.cpp   # Динамическая линия связи между двумя примитивами

└── ui/
    ├── MainWindow.h/.cpp       # Главное окно, панель управления, фильтры, синхронизация Сцена <-> БД
    └── ShapeCountDelegate.h/.cpp # Делегат отрисовки количества фигур в QTableView


Как устроена работа кода
Иерархия примитивов: базовый класс PrimitiveItem (наследник QGraphicsItem) инкапсулирует ID, размеры, подпись и список привязанных линий ConnectionLine. При перемещении фигуры срабатывает itemChange(), который пересчитывает координаты всех её линий. Классы EllipsePrimitive, RectanglePrimitive и PolygonPrimitive реализуют полиморфную отрисовку.

Слой БД: DatabaseManager работает через драйвер QSQLITE. При добавлении или удалении фигуры транзакционно обновляются записи связей (connected_ids) и пересчитывается общее число фигур каждого типа (type_count).

Связь UI и БД: MainWindow объединяет GraphicsScene и QTableView с моделью QSqlTableModel. Все действия на сцене (создание фигуры, проведение связи, удаление) мгновенно отражаются в БД и обновляют таблицу через model->select(). Фильтрация реализована через model->setFilter(...).

Сборка и запуск
Требуется CMake >= 3.16, компилятор с поддержкой C++17 и Qt 5 (модули Widgets, Sql).
Bash
mkdir build
cd build
cmake ..
cmake --build .
.\build\PrimitivesApp.exe
